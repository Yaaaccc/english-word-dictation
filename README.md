# 英语单词听写工具

本地英语单词听写工具，支持从扇贝、不背单词抓取生词，按日期存档，并提供网页听写、每日英语小短文 PDF 等功能。

## 快速开始

**方式一（推荐）**：双击 `一键听写.bat`

会自动完成：抓取扇贝今日新词 → 生成每日英语小短文 PDF → 启动本地服务并打开听写页面。

**方式二**：手动启动

```bash
node server.js
```

然后访问 <http://127.0.0.1:8787/>

> 环境要求：Node.js 22+（服务端使用了内置的 `node:sqlite` 模块）

## 主要功能

- 扇贝单词听写（新词 / 复习词）
- 不背单词生词本接入
- 每日英语小短文 PDF（自动生成到 `桌面\每日文章\`）
- 纸上默写（连续播放、乱序、听中文/英文切换）
- 词典查词（需本地词典库，见下方说明）

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `word-dictation.html` | 听写网页（主界面） |
| `server.js` | 本地服务（含查词接口） |
| `一键听写.bat` | 推荐入口：抓词 + 文章 PDF + 打开工具 |
| `grab-shanbay.js` / `bays4.js` | 扇贝抓取与解密脚本 |
| `grab-bubei.js` | 不背单词生词本抓取脚本 |
| `daily_article.py` | 每日文章 PDF 生成脚本 |
| `扇贝一键复制.html` | 不用 Node 的控制台一键复制方案（备用） |
| `2026-08-08.txt` 等 | 每天的新词存档（含例句 / 官方笔记 / 短语） |

## 关于词典库

查词功能依赖本地词典数据库 `词典/ecdict.db`（源自开源 ECDICT 英汉词典，约 100MB），**未包含在本仓库中**。如需使用查词功能，请自行准备该数据库文件放到 `词典/` 目录下。

## 隐私说明

登录凭证（`shanbay-auth.json`、`bubei-auth.json`）等敏感信息已通过 `.gitignore` 排除，不会上传。
