# 英语单词听写工具

本地英语单词听写工具，支持从扇贝抓取每日生词，按日期存档，并提供网页听写、每日英语小短文 PDF 等功能。

**在线版**：<https://yaaaccc.github.io/english-word-dictation/>（电脑每日自动抓取并同步，其他设备打开即用）

## 快速开始

**方式一（推荐）**：双击 `一键听写.bat`

会自动完成：抓取扇贝今日新词 → 同步 GitHub → 生成每日英语小短文 PDF → 启动本地服务并打开听写页面。

**方式二**：手动启动

```bash
node server.js
```

然后访问 <http://127.0.0.1:8787/>

> 环境要求：Node.js 22+（服务端使用了内置的 `node:sqlite` 模块）

## 主要功能

- 扇贝单词听写（新词 / 复习词）
- 每日英语小短文 PDF（自动生成到 `桌面\每日文章\`）
- 纸上默写（连续播放、乱序、听中文/英文切换）

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `word-dictation.html` | 听写网页（主界面） |
| `server.js` | 本地服务 |
| `一键听写.bat` | 推荐入口：抓词 + 同步 + 文章 PDF + 打开工具 |
| `grab-shanbay.js` / `bays4.js` | 扇贝抓取与解密脚本 |
| `sync-github.js` | 上传单词与日期索引到 GitHub（在线网站数据源） |
| `定时刷新扇贝.bat` | 每日定时任务调用：无头抓取 + 同步 |
| `daily_article.py` | 每日文章 PDF 生成脚本 |
| `今日单词/` | 每天的新词存档（含例句 / 官方笔记 / 短语） |
| `dates.json` | 网页「选日期」的索引文件，抓取后自动重建 |
