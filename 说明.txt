【扇贝单词听写工具 使用说明】

★ 最省事的方式（推荐）：

1. 双击「一键听写.bat」
2. 它会自动完成：
   ① 抓取扇贝今日【新词】（每日 50 个）→ 保存为当天日期文件（如 2026-08-08.txt）
   ② 自动生成【每日英语小短文 PDF】→ 保存到 桌面\每日文章\日期.pdf
   ③ 启动本地服务 → 自动打开听写页面并载入最新日期的单词
3. 勾选「乱序听写」，点「连续播放（纸上默写）」
4. 听完后把黑色窗口关掉即可（那个窗口是服务，关闭即停止）

第一次运行会弹出 Edge 窗口，登录一次扇贝，之后不用再登录。

★ 每日英语小短文 PDF：

- 每天抓完词后自动生成，位置：桌面\每日文章\2026-08-08.pdf（按日期命名）
- 文章来源（按优先级）：
  ① 如果有手写的文章文件（工具文件夹里的「日期.文章.txt」），PDF 用它
  ② 没有时退回用例句组装
- PDF 内容：
  ① 短文（今天新词写成的小文章，单词自动加粗）
  ② 单词与翻译：单词 + 音标、词性释义、例句、例句翻译

★ 词典查词（已内置）：

- 听写栏最下方有「查词」输入框，输入英文单词按回车或点「查词」
- 显示：音标、柯林斯星级（★）、词性、中文释义、英文释义、考试标签
- 使用本地词典 ecdict（77 万词条，完全离线）
- 第一次查词会加载词典数据库，稍等一两秒即可

★ 例句、官方笔记与短语：

- 每天抓取单词时自动附带：例句（英+中）、扇贝官方笔记（【辨析】【谐音】等）、常用短语
- 显示在【听写区底部的独立面板】里，顺序：单词 + 词性释义 → 例句 → 官方笔记 → 短语
- 播放单词时【不会】自动读例句；想听例句，点播放界面的「🔊 读例句」按钮
- 纸上默写（听英文）：底部面板同步显示当前词信息；听中文模式不显示（避免泄露答案）

★ 纸上默写（连续播放）：

- 自动连播默认【关闭】，每次进入都是手动逐个播放
- 播放单词时只读单词本身（中文模式读释义），例句用「🔊 读例句」按钮单独听
- 播放结束后，页面下方显示「本次朗读顺序」清单（乱序时就是乱序后的实际顺序）
- 「⏮ 从头播放」按钮、 「选择单词」下拉框
- 键盘：Enter / ↓ / → 下一个，↑ / ← 上一个，🔊 重播当前

★ 网页端切换日期：

页面左侧先选「来源」（扇贝新词 / 扇贝复习），再选「日期」下拉框；每天一个文件，默认载入该来源最新的日期。

★ 扇贝复习词：

- 「一键听写.bat」抓完今日新词后，会再抓「今日复习词」（REVIEW），
  单独保存为 shanbay-review-日期.txt，与每日新词互不覆盖。
- 网页端把「来源」切到「扇贝复习」，即可按日期听写当天的复习词。
- 复习词也带例句、短语、官方笔记，格式与新词完全一致。

★ 听写方式（页面左侧可切换）：

1. 听英文 → 写英文：读单词，你写英文拼写（默认）
2. 听中文（释义）→ 写英文：读中文释义，你写对应的英文单词

★ 发音语音（页面左侧，均已固定）：

1. 英文发音：Microsoft Ava Online（没有则自动用 Microsoft Aria Online）
2. 中文发音：Microsoft Yunyang Online（没有则自动用其他中文语音）

★ 不用 Node 的方式（备用，不含例句/官方笔记/短语）：

1. 双击「扇贝一键复制.html」，按里面步骤：打开扇贝页面 → F12 → 控制台 → 粘贴代码 → 回车 → 提示已复制 N 个单词
2. 打开 word-dictation.html，在单词框里 Ctrl+V 粘贴，勾选乱序开始听写

其它说明：
1. 每天抓取的 50 个新词按日期单独保存为一个 txt 文件，网页端可随时切换任意日期。
2. 抓取的是「今日新词」（未学过的词），不含复习词。
3. 接口返回 412（今日任务未生成）时会自动同步并重试，必要时自动生成今日任务。
4. 官方笔记直接来自扇贝；短语来自扇贝用户笔记，部分生僻词可能没有。
